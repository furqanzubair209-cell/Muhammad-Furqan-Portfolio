👋 About the Project

This is my personal developer portfolio, designed to showcase my software development journey, projects, professional experience, technical skills, certifications, achievements, and GitHub activity in a modern and interactive interface.

The portfolio focuses on a clean developer-oriented experience with responsive layouts, smooth animations, interactive sections, and support for both dark and light themes.

---

✨ Features

- 🎨 Modern developer-focused UI
- 🌙 Dark & Light mode
- 📱 Fully responsive design
- ⚡ Fast Vite-powered development
- 🎬 Smooth Framer Motion animations
- 🧩 Reusable React components
- 📂 Interactive project showcase
- 💼 Interactive experience timeline
- 🏆 Certifications & achievements section
- 📊 GitHub activity and statistics
- 📄 Interactive resume section
- 🖱️ Custom cursor experience
- ♿ Accessibility-focused UI
- 🎯 Reduced-motion support
- 🔍 SEO and social sharing metadata
- ❌ Custom 404 page
- 📱 Mobile-friendly navigation
- 🔗 Direct links to professional profiles and freelance platforms

🚀 Getting Started

Prerequisites

Make sure you have Node.js and npm installed.

Installation

Clone or download the repository and open the project directory:

cd muhammad-furqan-portfolio

Install dependencies:

npm install

Run Development Server

npm run dev

The portfolio will be available at the local URL provided by Vite, normally:

http://localhost:5173/

Build for Production

npm run build

Preview Production Build

npm run preview

Lint the Project

npm run lint
